在 GitHub 上怎么玩？
GitHub 会把 .html 当纯文本展示，所以直接点开仓库里的文件只会看到源代码。需要在仓库 Settings → Pages 里把 Source 设为 main 分支根目录并保存，然后访问
https://wuming1399.github.io/-/
就能看到这个入口页并直接游玩。想本地玩的话，双击 Untitled-2.html 即可（matter.min.js 需和它保持在同一目录）。
